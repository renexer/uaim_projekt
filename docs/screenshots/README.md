# Lista zrzutów ekranu do dokumentacji

Nie wygenerowano rzeczywistych obrazów w tym środowisku. Poniżej znajduje się dokładna lista screenów do wykonania ręcznie po uruchomieniu backendu, frontendu i aplikacji mobilnej.

## Web — `docs/screenshots/web/`

1. `web-01-home.png` — strona startowa z opisem gabinetu i przyciskami logowania/rejestracji.
2. `web-02-register.png` — formularz rejestracji pacjenta.
3. `web-03-login.png` — formularz logowania.
4. `web-04-services.png` — katalog usług z czasem trwania i ceną.
5. `web-05-therapists.png` — lista terapeutów z ocenami i usługami.
6. `web-06-therapist-details.png` — profil terapeuty, opinie i dostępne terminy.
7. `web-07-booking.png` — widok rezerwacji: usługa, terapeuta, termin i podsumowanie.
8. `web-08-appointments.png` — moje wizyty pacjenta.
9. `web-09-cancel-appointment.png` — komunikat po anulowaniu wizyty.
10. `web-10-consultations-reviews.png` — historia konsultacji i formularz opinii.
11. `web-11-staff-panel.png` — panel terapeuty/staff z listą wizyt i podsumowaniem konsultacji.
